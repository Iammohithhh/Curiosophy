# Curiosophy

Things I'm learning, papers I'm reading, and problems I'm trying to crack.
Live at **https://iammohithhh.github.io/Curiosophy**.

- Pages are in [`content/`](content/), which also works as an Obsidian vault.
- The site is built with [Quartz](https://quartz.jzhao.xyz), downloaded at build time by [`site/build.sh`](site/build.sh). Every push to `main` publishes it.
- Preview locally: `site/build.sh --serve`, then open http://localhost:8080.
